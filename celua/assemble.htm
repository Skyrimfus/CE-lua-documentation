assemble

assembles a single line of code and returns a byte array of the generated code.

assemble( line [, address = 0 [, assemblePreference = 0 [, bSkipRangeCheck = false]]] )


Parameters
lineassembly line
address[optional] target address where the line is supposed to be assembled
default(0)
assemblePreference[optional] apNone=0, apShort=1, apLong=2, apFar=3
default(0)
bSkipRangeCheck[optional] boolean. Which will skip range checks if true and just assembles it, no matter of how wrong the result will be
default(false)
Return Value

On success:
Byte table representation of the given line

On Fail:
nil, or error message
